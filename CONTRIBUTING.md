# Contributing

This is an NVIDIA OSS Type 2 repository: the source code is public, but
development and contribution intake are handled inside NVIDIA.

This project is currently not accepting contributions.

External pull requests, patches, feature requests, and issue-driven design
proposals are not part of this repository's contribution model at this time.
NVIDIA maintainers make changes through the maintainer workflow in
[`GOVERNANCE.md`](GOVERNANCE.md), including the required internal IP review
before release.

For vulnerability reports, follow [`SECURITY.md`](SECURITY.md). Do not file
public GitHub issues for security concerns.
